## Your mission: a profile card with only Tailwind

Tailwind is already loaded in the page. Style the card by adding **classes in the HTML**. There's no CSS file in this lesson.

1. **The page.** Give `<body>` the classes `bg-slate-100 min-h-screen flex items-center justify-center p-6`.
2. **The card.** Give the `<article>` the classes `bg-white rounded-2xl shadow-lg p-6 max-w-sm w-full`.
3. **The top row.** Make the `<header>` a row: `flex items-center gap-4`. Make the image round: `w-16 h-16 rounded-full`.
4. **The text.** Style the name with `text-xl font-bold`, the job title with `text-slate-500`, and the bio paragraph with `mt-4 text-slate-700 leading-relaxed`.
5. **The button.** Give the button `mt-6 w-full bg-sky-500 hover:bg-sky-600 text-white font-bold py-2 rounded-lg`.

✅ **You're done when** the preview shows a centered white card with a round photo next to the name, and a blue button that darkens when you hover it.
