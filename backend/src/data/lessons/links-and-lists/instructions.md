## Your mission: build a recipe page

Build "My Recipe Site" with a menu, a recipe and a small glossary.

1. **The menu.** Under the `<h1>`, add a `<ul>` with three links:
   - `Home` → `#top`
   - `Recipe` → `#recipe`
   - `MDN Web Docs` → `https://developer.mozilla.org`, opening in a new tab (remember `rel="noopener noreferrer"`)
2. **The recipe heading.** Add an `<h2>` with the text `Pancakes` and `id="recipe"`.
3. **The steps.** Below it, add an `<ol>` with at least four steps. The first step is `Mix the ingredients:`.
4. **A list inside a list.** Inside that first step's `<li>`, add a `<ul>` of three ingredients.
5. **A glossary.** Add an `<h2>` called `Cooking words`, then a `<dl>` with two terms: `Whisk` and `Batter`, each with a short description.
6. **Contact.** End the page with a `<p>` containing a link `Email the chef` that opens an email to `chef@example.com`.

✅ **You're done when** the steps are numbered, the ingredients sit inside step 1, and clicking `Recipe` in the menu jumps to the recipe.
