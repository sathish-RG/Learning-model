## Your mission: build a landing page with Flexbox

The page is locked, and colors and spacing are already done. Use only Flexbox properties in `styles.css`.

1. **The navbar.** Make `.navbar` a flex container with the logo on the far left and the button on the far right (`justify-content: space-between`), all vertically centered (`align-items: center`).
2. **The menu.** Make `.nav-links` a flex container with a `gap` of `24px`, so the links sit in a row.
3. **The hero.** Center `.hero-content` perfectly inside `.hero`, both horizontally and vertically.
4. **The buttons.** Make `.hero-actions` a flex container with a `12px` gap, allowed to wrap onto a new line.
5. **Equal features.** Make `.features` a flex container with a `16px` gap, and give each `.feature` `flex: 1` so all three are the same width.

✅ **You're done when** the navbar has the logo on the left and the button on the right, the hero text sits in the exact middle of the dark area, and the three feature cards are equally wide.
