## Your mission: loop practice

All output goes to the console.

1. **Count laps.** Use a `for` loop to log `"Lap"` and the lap number, for laps 1 to 5.
2. **Running total.** Use a `for` loop to add up every number from 1 to 100, then log the total.
3. **FizzBuzz.** For every number from 1 to 15, log:
   - `"FizzBuzz"` if it divides by both 3 and 5
   - `"Fizz"` if it divides by 3
   - `"Buzz"` if it divides by 5
   - otherwise, the number itself

   *Hint:* `n % 3 === 0` means "divides by 3". Check FizzBuzz first!
4. **Saving up.** You save `150` every week. Use a `while` loop to find how many weeks it takes to reach at least `1000`, then log the number of weeks.
5. **Count the vowels.** Use `for...of` to count the vowels (`a`, `e`, `i`, `o`, `u`) in `"javascript is fun"`, then log the count.

✅ **You're done when** the console shows `Lap 1` to `Lap 5`, then `5050`, then FizzBuzz from `1` to `FizzBuzz`, then `7` and `5`.
