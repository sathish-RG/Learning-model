## Your mission: decorate the Fruit Market

The HTML is finished and locked. Write all your rules in `styles.css`. For now, use simple color names like `navy` or `orange`; you'll learn better colors in the next lesson.

1. **Element selector.** Make every `h2` `navy`.
2. **Id selector.** Make the element with the id `title` `purple`.
3. **Descendant selector.** Make the links inside `nav` `darkorange`.
4. **Grouping.** In **one** rule, make both `.note` and the paragraph inside `footer` `gray`.
5. **Win the specificity battle.** Add `.sale { color: red; }`. It won't work, because the rule that was already in the file is more specific. Without deleting that rule and without `!important`, write a selector for the sale items that **wins**.

✅ **You're done when** the title is purple, the section headings are navy, the menu links are orange, and only the two sale items are red.
