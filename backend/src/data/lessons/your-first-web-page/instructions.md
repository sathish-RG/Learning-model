## Your mission: build your first web page

The editor is almost empty. Build the full page skeleton yourself. (Peek at the lesson if you get stuck!)

1. **Start the page.** On the first line, write `<!DOCTYPE html>`.
2. **Build the house.** Add `<html lang="en">` and its closing tag. Inside it, add a `<head>` and a `<body>`.
3. **Fill the backstage.** Inside `<head>`, add `<meta charset="UTF-8" />` and a `<title>` that says `My First Page`.
4. **Say hello.** Inside `<body>`, add an `<h1>` that says `Hi, I'm` followed by your name.
5. **Tell your story.** Below the heading, add a `<p>` with one sentence about why you're learning to code.
6. **Leave a note.** Add a comment above the `<h1>` that says what this page is.

✅ **You're done when** the preview shows your heading and your paragraph, and every tag you opened is closed in the right order.
