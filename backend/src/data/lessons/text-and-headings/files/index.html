The Story of the Web How it started In 1989, Tim Berners-Lee, a scientist at CERN, suggested a way for computers to share documents using links. It was free for everyone to use. The first website The first website went online in 1991. It explained what the web was and how to build your own pages. The power of the Web is in its universality. The web today Today, billions of people use the web every day, and everyone can publish on it. Every page starts with [the html tag]. CERN Esplanade des Particules 1 1211 Geneva, Switzerland
