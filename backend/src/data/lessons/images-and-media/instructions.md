## Your mission: build a photo gallery

Build a small gallery using the photos and video linked in the starter comments.

1. **Three pictures with captions.** Under the `<h1>`, add three `<figure>` elements. Each one holds an `<img>` and a `<figcaption>`. Use the grapefruit, elephant and surfer photos.
2. **Describe each photo.** Give every image a meaningful `alt`. Describe what's *in* the photo (not "image" or the file name).
3. **Save their seats.** Add `width` and `height` to each image. *Hint:* the sizes are in the file names, e.g. `elephant-660-480.jpg` is 660 wide and 480 tall.
4. **A video.** Below the gallery, add an `<h2>` that says `A flower opening`, then a `<video>` with `controls` and `width="400"`. Add two `<source>` tags (the WebM first, then the MP4), and a fallback sentence inside.

✅ **You're done when** the three photos show with captions, and the video plays when you press play in the preview.
